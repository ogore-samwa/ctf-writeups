# Project Phoenix — LabEx Linux Administration

## Platform
LabEx Corporation

## Category
Linux System Administration

## Challenge Summary
A 5-day progressive scenario as a junior system 
administrator at LabEx Corporation working on 
Project Phoenix.

## Day 1 — System Reconnaissance
### Commands Learned
- whoami — confirm user identity
- uname — check OS information
- who — see active users on system
- id — inspect user and group memberships
- top — monitor system processes and resources
- > and >> — output redirection for documentation

## Day 2 — Digital Architect
### Commands Learned
- mkdir — create directory structures
- mv — move and rename files
- cp — copy files
- tar — archive old logs
- rm — remove unnecessary files

## Day 3 — Log Investigator
### Commands Learned
- grep — filter and extract critical log information
- dmesg — investigate kernel and hardware issues
- diff — compare configuration files
- Command pipelines — chain commands efficiently

## Day 4 — Fortress Guardian
### Skills Learned
- File permissions and ownership management
- chown — assign ownership to users and groups
- setgid permissions — collaborative workspace setup
- Directory security configuration

## Day 5 — Keeper of the Keys
### Commands Learned
- User account creation and management
- Home directory configuration
- passwd — password policy implementation
- Group membership management
- Disabling unauthorized access

## Key Takeaway
These commands form the complete foundation of 
professional Linux system administration covering
reconnaissance, file management, log analysis,
security hardening and user management.
